Демо-приложение и два библиотечных модуля для простой реализации Speech to Text  (STT) и Text to Speech (TTS) на русском языке локально на устройстве. 
Для STT используется библиотека Vosk с моделью русского языка размером около 50 Мб. Для TTS - встроенные средства Андроид, список поддерживаемых голосов можно выбрать и дополнить в разделе Язык и клавиатура - Преобразование текста в речь приложения Настройки.
Модули можно вместе или по отдельности экспортировать в свой проект из проекта с демо приложением либо скопировать их каталоги и указать на использование модулей в .build файлах проекта.
